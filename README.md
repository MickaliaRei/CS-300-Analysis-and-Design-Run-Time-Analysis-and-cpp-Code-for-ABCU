# CS-300-Analysis-and-Design-Run-Time-Analysis-and-cpp-Code-for-ABCU
These projects include the run-time analysis and cpp code for the ABCU advising department which will accommodate the advisors while helping students with scheduling their courses.

1. What was the problem you were trying to solving in the projects for this course?
   The purpose of this project was to help the ABC University's computer science department advisors to access course information for      their students when helping them schedule their courses for the school terms. The advisors needed the program to quickly input the      courses within the program, print a list of the courses in alphanumeric order and print the title and prerequisites of a specific       course.

3. How did you approach the problem?
   I approached this problem by first gaining an understanding of the different data structures such as learning their advanatages and
   disadvantages and understanding how differently each data structure worked. For this project, I focused on the Vector, Hash table and
   Binary Search Tree data structures. Understanding how each data structure works is an important aspect to consider when designing a
   program as data structures determine how data will be organized, stored, accessed and managed within a system. Choosing the most
   appropriate data structure for a system will ensure a program will run more efficiently, use less memory and process data faster.

4. How did you overcome any roadblocks while going through the activities or project?
   Throughout this project, I did encounter a few roadblocks. For example, during the implementation of the Hash Table data structure,
   I had to make sure my program handled collisions appropriately. To overcome this roadblock, I implemented the pointer feature so
   that any additional course that had was placed in the same hash location with another course will be connected to the existing node.

5. How has your work on this project expanded your approach to designing software and devloping programs?
   After completing this project, my approach to designing software and developing programs has expanded. Before this project, I would
   strictly focus on making sure my code works as intended and solve the existing program. After this project, I now understand that
   designing software and developing programs is more than just having a workable code; it also involves considering other aspcets
   such as what data structure would be more appropriate to be used in the program depending on what the program is needed for.

6. How has your work on this project evolved the way you write programs that are maintable, readable, and adaptable?
   Working on the project has helped to evolve the way I write programs as I now take full advantage of writing pseudocodes before
   attempting to develop the actually code. Using the pseudocodes first has helped me to have a an outline of what my code will be and
   also helps me to keep my code as orgainzed and readable as possible before developing the code.
